# Style Profile — 写作风格基线

> 基于期刊论文写作惯例，面向 SCI 三区/四区英文期刊

---

## 1. Sentence-Level 风格

| 维度 | 目标风格 | 反例（避免） |
|---|---|---|
| 句子长度 | 均值 20-30 词，长句 < 50 词 | 连续的复合从句链 |
| 主动/被动 | 主动为主（We propose...），被动用于方法 | 通篇被动 |
| 第一人称 | 使用 "we"（本文作者团队），不使用 "I" | 避免 "the authors" 替代 "we" |
| 时态 | Abstract 现在时 → Intro 现在时/现在完成时 → Method 过去时 → Result 过去时 → Conclusion 现在时 | 混用 |
| 连接词 | However, Therefore, In addition, Furthermore, Specifically | 不要干巴巴的 "and" 连接 |

## 2. 词汇偏好

**领域核心术语**（基于文献统计）：
- lane change behavior, lane-changing maneuver
- surrogate safety measure (SSM)
- crash risk / collision risk / risk assessment
- vehicle trajectory data
- risk field / potential field
- fault tree analysis (FTA)
- naturalistic driving data
- time-to-collision (TTC), post encroachment time (PET)
- real-time risk estimation

**高频学术动词**：
- propose, develop, introduce, establish — 提出方法
- evaluate, assess, quantify, estimate — 评价
- demonstrate, indicate, reveal, validate — 展示结果
- address, overcome, mitigate — 解决问题

## 3. 段落节奏

**引言段**：泛 → 专 → 问题 → 方案
**方法段**：概念 → 公式 → 解释 → 意义
**结果段**：发现 → 数据支持 → 对比解释
**讨论段**：重申发现 → 与文献对比 → 含义

## 4. 图表风格（领域惯例）

- **框架图**：2-4 色流程图，用箭头展示数据流
- **数据图**：黑色/灰色点线 + 彩色区分组别
- **表格**：三线表，左对齐，数字居中
- **参考文献格式**：IEEE 或 Elsevier 风格

## 5. 篇幅估计 (SCI 三区/四区期刊)

| 节 | 估计段落 | 估计词数 |
|---|---|---|
| Abstract | 1 段 | 150-250 |
| Introduction | 4-6 段 | 800-1200 |
| Literature Review | 3-5 段 | 600-1000 |
| Methodology | 6-10 段 | 1500-2500 |
| Results | 4-6 段 | 1000-1500 |
| Discussion | 3-4 段 | 600-1000 |
| Conclusion | 2-3 段 | 400-600 |
| **总计** | | **5000-8000** |
