## 2. 关键论文详解

### E1 — F-F Diagram (IEEE T-ITS, 2025)

- **期刊档次**：SCI 一区 (Transportation Science & Technology), IF~7.5
- **核心贡献**：提出基于场论的两维换道风险指标 F-F Diagram
- **方法论**：
  - 构建驾驶风险场（驱动力场 + 风险排斥场）
  - 提出 AdaCGBC 自适应梯度优化算法标定参数
  - GMM 聚类的两维风险等级划分
  - 使用 highD 数据集（1,122 个换道样本）
- **写作特点**：
  - Introduction: 全球事故统计 → 换道风险 → 传统SSM局限 → 风险场未解决的问题 → 本文方案
  - Related Work 4个子节系统梳理（SSM → 风险标签 → 换道评估 → 安全场）
  - 方法节从物理类比出发，逐步推导数学模型
  - 结论强调实际应用前景（ADAS集成）
- **可学之处**：物理类比法引入风险场、参数优化算法创新、两维风险可视化（F-F图）

### E2 — Risk Map Early Warning (Accident Analysis & Prevention, 2024)

- **期刊档次**：SCI 一区, IF~6.0
- **核心贡献**：提出基于风险地图的高速公路车辆预警方法
- **方法论**：
  - MTTC（二维TTC）→ 概率变换 → RI（风险指标）
  - 单车风险地图 → 叠加 → 全局风险地图
  - 动态分类预警阈值
- **写作特点**：
  - Introduction 末尾有明确的 3 条编号贡献（numbered contributions）
  - Literature Review 分为风险指标和预警两个子节
  - 每个公式都有详细的文字解释
  - 讨论节对方法论局限性坦诚讨论

### E3 — Improved Risk Estimation (J. Transportation Safety & Security, 2022)

- **期刊档次**：SCI 四区, IF~2.0
- **核心贡献**：引入 Safety Margin 概念，建立考虑制动能力和反应时间的换道风险估计模型
- **方法论**：
  - Safety Margin → 碰撞概率 + 碰撞严重度
  - 高D数据集 1,536 换道样本
  - ANOVA 分析车辆类型/换道方向/交通流影响
- **写作特点**：
  - Introduction 定位在"两点未解决空白"
  - 3 条编号贡献，每一条是一个具体的创新点
  - Literature Review 覆盖 deterministic 和 model-based 两大类 SSM
  - 风险定义为 "probability × severity" 经典框架

### C4 — 冲突风险场构建 (中国公路学报, 2026)

- **期刊档次**：中文核心/EI
- **核心贡献**：从"确定性"到"随机性"的范式转变，提出交通冲突风险场模型
- **方法论**：
  - GMM 建模轨迹概率分布 → 行为克隆 + 变分推断
  - 定义的场强为概率密度泛函内积（数学上更严格）
  - 推导出闭式解（马氏距离平方的高斯核形式）
  - ExiD + 实地采集数据验证
- **写作特点**：
  - 理念先行：开篇提出两个核心局限（行为确定性、空间离散性）
  - 每个局限都用示意图标注
  - 数学推导严谨（证明闭式解存在性）
  - "范式转变"用语提升论文高度
  - 大量场景验证（合流/换道/并排/跟驰/群车）

## 3. 共同写作模式总结

### 3.1 Introduction 标准四步法

1. **宏大开篇**：全球/全国事故统计数据（WHO, NHTSA）
2. **聚焦问题**：换道/合流/汇入行为的具体安全影响
3. **文献批评**：现有方法局限（2-3 个 gap，编号或分段）
4. **本文方案 + 贡献**：numbered contributions → paper organization

### 3.2 数据描述固定结构

```
数据集名称（highD/NGSIM/ExiD/UTE/自采）
→ 采集方式（无人机/固定摄像机）
→ 研究区域（位置、车道数、长度）
→ 数据频率（10Hz/25Hz）
→ 样本提取标准（时间窗口、滤除条件）
→ 预处理（去噪/平滑/异常值处理）
→ 最终样本量
```

### 3.3 方法论文标配

- **框架图**（flowchart）通常是第一个图，显示整体流程
- **数学模型**：从显式公式开始，逐步引入复杂性
- **参数标定/优化算法**：GA/PSO/Adam/自创算法
- **多模型对比**：与 2-4 种基线方法比较

### 3.4 结果呈现模式

- 先特征分析（统计描述/T检验/相关性分析）
- 再模型性能（准确率/精确率/召回率/F1 表格）
- 可视化（分布图/散点图/箱线图）
- 敏感性/鲁棒性分析

### 3.5 Discussion/Conclusion 模式

- 关键发现总结
- 与现有研究的对比
- 实践意义
- 局限性 + 未来工作
